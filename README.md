# 🎁 GAI Gift — AI-Powered Luxury Gifting Platform

**GAI Gift** is a premium, AI-powered gifting platform designed to make gift discovery more personalized, intelligent, and convenient.

The platform combines **luxury gifting, personalized recommendations, occasion-based discovery, and data-driven insights** into a modern digital gifting experience.

## ✨ Key Features

* 🎁 **Curated Luxury Gifts** — Discover premium gifts across multiple categories.
* 🤖 **AI Gift Recommendations** — Personalized suggestions based on recipient, occasion, preferences, and budget.
* 🎉 **Occasion-Based Discovery** — Explore gifts for birthdays, anniversaries, weddings, corporate events, festivals, and more.
* 💰 **Budget-Based Selection** — Find suitable gifts across different price ranges.
* 👤 **Personalized Gifting Experience** — Designed around the recipient and gifting occasion.
* 🛍️ **Product Management** — Manage products, categories, occasions, pricing, and product information.
* 📊 **Analytics Dashboard** — Track business and customer-related metrics.
* 🔐 **Admin Management** — Dedicated functionality for managing the gifting catalog.
* 📈 **Business Intelligence** — Designed to support insights such as demand trends, revenue, customer behavior, and product performance.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Ankitatan/GAI-Gift.git
cd GAI-Gift
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

### 3. Activate the environment

**Windows:**

```bash
venv\Scripts\activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the application

```bash
streamlit run app.py
```

The application will open in your browser.
